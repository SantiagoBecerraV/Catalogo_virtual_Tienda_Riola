# RIOLA — Catálogo virtual

Sitio estático de tres archivos:

- `index.html` — estructura de la página
- `styles.css` — estilos (tema claro/oscuro incluido)
- `app.js` — datos, vistas y enrutado (`#/`, `#/disenos`, `#/siluetas/:id`)

Las imágenes están en `assets/`. Abre `index.html` en el navegador, no requiere instalación ni build.
